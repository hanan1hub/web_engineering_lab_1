HTML Elements Used in This Page

  1. <!DOCTYPE html> — tells the browser this is an HTML5 document
  2. <html> — the root element wrapping the whole page
  3. <head> — holds page info not shown directly on screen
  4. <meta> — sets page settings like character encoding
  5. <title> — sets the text shown on the browser tab
  6. <body> — contains all visible page content
  7. <h1> — main heading, largest and most important
  8. <h2> — sub-heading, one level below h1
  9. <h3> — smaller sub-heading, used for section titles
  10. <p> — a paragraph of text
  11. <ul> — an unordered (bulleted) list
  12. <ol> — an ordered (numbered) list
  13. <li> — a single item inside a list
  14. <a> — a clickable link to another page or email
  15. <hr> — draws a horizontal line to separate content
  16. <header> — groups intro content like a name and title
  17. <address> — marks up contact information
  18. <br> — inserts a single line break
  19. <strong> — makes text bold to show importance
  20. <em> — makes text italic to add emphasis
  21. <footer> — groups closing content like a copyright note
